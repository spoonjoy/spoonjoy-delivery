# Planning: Spoonjoy Cross-Client Delivery

**Status**: approved
**Created**: 2026-07-20 19:58

## Goal

Build and pilot a small, production-grade delivery system that carries one Spoonjoy product contract through web/backend, native Apple, and MCP/agent implementations to independently verified exact releases and terminal cleanup. Only a provider-backed Release Set may declare a Product Change shipped.

## Upstream Work Items

- Codex task `019f2e25-2fc3-75b2-8ba3-335f3777115a`: its protected source-owner handoff and byte-identical receiver acknowledgment are prerequisites for Unit 13b; it retains exclusive native/TestFlight/provider-release ownership until terminal two-sided validation succeeds.

## Scope

### In Scope

- Establish spoonjoy-delivery as the protected, tested control plane for cross-client contracts, authorization, evidence, finalization, and cleanup.
- Define strict versioned records and semantic validation for Product Contracts, Product Changes, Contract Packs, provider operations, handoffs, attestations, recovery, cleanup, and Release Sets.
- Establish a single-operator V1 authority model with separate least-privilege review and ledger principals, independently verifiable actor/workflow provenance, and append-only ownership/release records.
- Preserve repository ownership boundaries: domain contracts in spoonjoy-v2, delivery coordination in spoonjoy-delivery, and native locks/provenance in spoonjoy-apple.
- Integrate exact-source web/backend, native Apple, MCP/protocol, and agent-experience evidence without moving provider credentials into the delivery repository or untrusted workflows.
- Require compatibility proof for the current and previous native contract/build where the Product Change affects installed clients or queued work.
- Pilot the system on Recipe Photo Studio after the active release task transfers ownership, including semantic parity, live provider evidence, installed proof where hardware exists, and run-owned cleanup.
- Produce durable operator documentation, rollback/containment paths, hostile reviews, and exact release evidence.
